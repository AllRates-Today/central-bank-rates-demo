Exchange rate API demos

Plain HTML, CSS and JavaScript. Each page is one file; view source and copy it. Rates come from the keyless endpoints, no API key needed.

  • Currency converter with a free keyless exchange rate API
    Vanilla JS converter on ECB reference rates from the AllRatesToday open API. No API key, CORS enabled.
  • CSS marquee FX ticker fed by a free exchange rate API
    Pure-CSS scrolling ticker; the rates come from one keyless fetch to allratestoday.com.
  • Compare central bank official exchange rates
    Same currency pair as published by RBI, Fed, ECB, BoE, BoJ and PBoC today, from the keyless central-bank endpoint.

The endpoints used:

GET https://allratestoday.com/api/open/latest/USD
GET https://allratestoday.com/api/open/central-bank/rbi

Keyless use needs a visible link: Exchange rates by AllRatesToday. Docs at allratestoday.com/open-api · Back to the central bank dashboard
